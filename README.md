# Hashing Performance Study

## Project Overview
This project studies hash functions, collision resolution techniques, and hashing performance using the C programming language.

## Project Contents
- `hash_table 2.c` — C source code.
- `program.exe` — Compiled executable for Windows.
- `Hashing-Performance-Study-Report.pdf` — Academic project report.

## Technologies Used
- C Programming Language
- Hash Tables
- Hash Functions
- Collision Resolution Techniques

## Purpose
The purpose of this project is to explore hash table implementation and study the performance of hashing techniques.
